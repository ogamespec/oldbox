# Клавиатура: SDL3 scancode -> PC/AT set 1

`Machine::key_event()` получает стабильный `SDL_Scancode` из SDL3-фронтенда и
переводит его в **make code set 1**. Для расширенных клавиш перед make/break
кодом отправляется префикс `E0` (так же, как реальная PS/2-клавиатура).
Таблица находится в `src/keymap.cpp`, тип результата — `oldbox::Set1Key`
(`code`, `extended`), сама функция — `sdl_scancode_to_set1()`.

## Что было сломано

Старая таблица была сдвинута относительно `SDL_scancode.h`:

| SDL-код | клавиша | было | стало |
|---|---|---|---|
| 225 | LShift | не мапилась | `2A` |
| 226 | LAlt | `2A` (Shift!) | `38` (Alt) |
| 228 | RCtrl | не мапилась | `E0 1D` |
| 229 | RShift | не мапилась | `36` |
| 230 | RAlt | не мапилась | `E0 38` |
| 55 / 56 | Period / Slash | не мапились | `34` / `35` |
| 57 | CapsLock | не мапилась | `3A` |
| 68 / 69 | F11 / F12 | не мапились | `57` / `58` |
| 73…82 | Insert…Up | сдвиг: Right→`55`, Left→`47`, Down→`48`, Up→`50` | `E0 52/47/49/53/4F/51/4D/4B/50/48` |
| 83…99 | NumLock, keypad | `52/54/56/2B/0E/7D…8F` | `45/35/37/4A/4E/1C/4F…53` |
| 101 | Menu | не мапилась | `E0 5D` |
| 103 | KP `=` | не мапилась | `59` |
| 104…115 | F13…F24 | не мапились | `64…6F` |
| 224 | LCtrl | `1D` | `1D` (без изменений) |

Именно поэтому **Alt работал как Shift**, а стрелки были перепутаны:
SDL `Up=82` отдавал set-1 `Down=50`, `Down=81` — `Up=48`, `Left=80` — Home,
`Right=79` — вообще `0x55`.

## Итоговые правила

- Буквы/цифры/знаки — обычные set-1 коды (`A=1E`, `1=02`, `,=33`, `. =34`,
  `/ =35`, `; =27`, `' =28`, `` `=29``, `[=1A`, `]=1B`, `\=2B`).
- `LShift=2A`, `RShift=36`, `LCtrl=1D`, `LAlt=38` — без `E0`.
- `RCtrl=E0 1D`, `RAlt=E0 38`, `LGUI=E0 5B`, `RGUI=E0 5C`, `Menu=E0 5D`.
- Стрелки, Insert/Delete/Home/End/PgUp/PgDn — `E0` + базовый код
  (`Up=48`, `Down=50`, `Left=4B`, `Right=4D`, `Home=47`, `End=4F`,
  `PgUp=49`, `PgDn=51`, `Insert=52`, `Delete=53`).
- Keypad: цифры/операторы — базовые коды (`KP8=48` и т.д.), `KP Enter=E0 1C`,
  `KP Divide=E0 35`, `KP Multiply=37`, `KP Minus=4A`, `KP Plus=4E`,
  `KP Equals=59`.
- `PrintScreen` (E0 2A E0 37) и `Pause` (E1 1D 45) **не мапятся**: одним
  базовым байтом они превратились бы в `KP *` и `NumLock`. Для них нужна
  отдельная последовательность, её можно добавить позже.

## Dangerous Dave 2

Игра ставит собственный INT 9 и читает порт `0x60`; её таблица:

```
up 0x48, right 0x4D, down 0x50, left 0x4B, Ctrl 0x1D, Alt 0x38
```

`E0`-префикс она не разбирает, но и не мешает: код `0xE0` просто попадает в
`keys[0xE0]`, а следующий за ним `0x48/0x4D/0x50/0x4B` — в нужную ячейку.
Так же ведёт себя реальная клавиатура, поэтому префикс оставлен.

## Повторное чтение порта 0x60

Регистр данных 8042 не очищается при чтении порта `0x60`: чтение сбрасывает
только флаг OBF (бит 0 статуса), а сам байт остаётся в регистре до прихода
следующего. Это важно для цепочек INT 9: обработчик может сам прочитать
скан-код, а затем вызвать предыдущий обработчик, который читает `0x60` ещё
раз. На реальной клавиатуре второе чтение возвращает тот же скан-код.

Раньше `Keyboard::read_data()` при пустой очереди возвращал `0xFF`. Из-за
этого BIOS Award при повторном чтении видел «ошибку клавиатуры», пищал через
PC Speaker и не клал клавишу в буфер `0040:001E`. Симптом: в установщике
WORLD9 (`INSTALL.EXE`, оболочка CyberWare VFS) поле ввода пароля «Security
System» принимало только редкие символы (`*`), Enter не срабатывал, а на
каждое нажатие раздавался хрип динамика.

Теперь последний прочитанный байт хранится в `output_latch_` и возвращается,
пока не придёт следующий. Для этого есть тест
`keyboard_output_register_keeps_last_byte_after_read`.

## Тесты

- `keyboard_extended_keys_send_e0_prefix` — `E0 48`, `E0 C8`, правый Ctrl.
- `keyboard_sdl_scancode_mapping_audit` — таблица всех групп клавиш,
  включая исправленные стрелки, keypad и модификаторы; `PrintScreen`/`Pause`
  обязаны остаться нулевыми.
- `machine_key_event_maps_sdl_arrows_and_alt` — сквозной путь
  `Machine::key_event(SDL Up/Alt/Left)` до байтов в очереди 8042.
- `dd2_arrow_and_alt_scancodes_reach_game` — игра загружается с `dd2.img`,
  Right/Alt отправляются через `Machine::key_event`, и проверяется
  `keys[0x4D]`/`keys[0x38]` в INT 9-таблице DD2 (`DGROUP:0x2B82`), включая
  release.

Все тесты проходят на Linux и Windows (`ctest`).
