# I/O и A20

## I/O-карта

`Bus` содержит 65536-элементную таблицу указателей `IoDevice`. Регион
занимает один или несколько портов; пересечения запрещены, кроме повторного
маппинга того же устройства.

Ключевые регионы:

| Диапазон | Устройство |
|---|---|
| 0x000–0x00F, 0x080–0x08F, 0x0C0–0x0DF | 8237 DMA (master/slave/pages) |
| 0x020–0x021, 0x0A0–0x0A1, 0x4D0–0x4D1 | 8259 PIC + ELCR |
| 0x040–0x043, 0x061 | 8254 PIT / speaker |
| 0x060, 0x064 | 8042 keyboard/mouse |
| 0x070–0x071 | CMOS/RTC |
| 0x092, 0x0CF9 | PIIX4 A20/reset |
| 0x1F0–0x1F7, 0x3F6, 0x170–0x177, 0x376 | PIIX4 IDE/ATA |
| 0x3B0–0x3BF, 0x3C0–0x3DF | S3 VGA |
| 0x3F0–0x3F5, 0x3F7 | 82077AA FDC |
| 0x220–0x22F, 0x330–0x331, 0x388–0x389, 0x620–0x623, 0xE20–0xE23 | AWE64 |
| 0xCF8–0xCFF | PCI config mechanism #1 |

16/32-битные accesses:

- если весь диапазон принадлежит одному `IoDevice`, вызывается его
  `io_read16/32` (или `io_write16/32`) — это нужно для IDE data port,
  `OUT DX,AX` в S3 и EMU8000;
- иначе Bus собирает значение из байтов/слов, что корректно для
  несмежных/частично замапленных портов;
- на границе 0xFFFF доступы не выходят за таблицу: старшие байты читаются
  как 0xFF, записи игнорируются.

Записи в port 0x80 сохраняются в историю POST-кодов.

## I/O-привилегии

Проверка выполняется в `Cpu::check_io_privilege`:

- real mode — доступ разрешён;
- protected mode, CPL 0 — разрешён;
- protected mode, CPL ≤ IOPL — разрешён;
- иначе проверяется I/O permission bitmap в TSS: `TR + 0x64` содержит
  смещение карты; бит 1 запрещает порт; отсутствие TSS/бита даёт #GP(0).
- V86 всегда идёт через bitmap, IOPL не ослабляет проверку.

CLI/STI/HLT также проверяют CPL/IOPL. POPF/IRET не позволяют ring 3 менять
IOPL/IF.

## A20

A20 реализован в `Bus`: при выключенном gate адрес маскируется
`addr &= ~(1 << 20)`, поэтому `0x100000` алиасится на `0x000000`.

Маска применяется только к доступам процессора. Шинные мастера (8237 DMA)
выставляют адрес сами, и на реальной плате A20 их не гейтит: иначе
дисковые буферы FreeDOS в HMA (0x10xxxx) при выключенном A20 попадали бы
в младшую память (наблюдалось как запись секторов FAT поверх текстового
экрана 0xB8000). Поэтому у `Bus` есть «сырые» доступы
`read8_raw`/`write8_raw`/…, их использует `Dma::read_byte`/`write_byte`.
Тест: `dma_bus_master_ignores_a20_gate`.

Источники управления:

- port 0x92 (PIIX4 fast A20/reset), bit 1;
- 8042 command 0xD1 (write output port), bit 1; 0xD0 читает сохранённый
  output port;
- `Piix4::a20()` и `Bus::set_a20()` для внутренних сбросов.

Тесты: `bus_port80_history_and_a20_alias`,
`port92_and_keyboard_8042_a20_gate`, `mode_real_segment_wrap_and_a20`.
